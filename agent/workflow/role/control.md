# Control

## Rank

- architect
- manager
- reviewer
- worker

## Rule

- Higher roles may approve or reject lower role artifacts.
- Lower roles may ask higher roles questions.
- Worker can ask upward but cannot approve or reject another role.
- Architect is the default human chat interface.
- Human does not need to chat directly with manager, reviewer, or worker.
- Higher roles may start multiple lower role sessions when parallel work is useful.
- Parallel worker execution requires distinct experiment claims.
