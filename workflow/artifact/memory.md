# Memory Artifact

## Purpose

A memory artifact preserves useful knowledge when a session ends.

It helps the next session avoid repeating mistakes.

## Required Sections

Memory must include:

- session role
- task history
- accepted changes
- rejected changes
- common failure modes
- useful project knowledge
- next session advice

## Worker Memory

Worker memory should focus on:

- implementation patterns
- rule mistakes
- commands that matter
- files that are risky
- reviewer feedback

## Reviewer Memory

Reviewer memory should focus on:

- common worker mistakes
- recurring risks
- architecture concerns
- review criteria that were useful

## Rule

Memory should be concise.

Memory should not duplicate full logs.

Memory should point to summaries and results when needed.
