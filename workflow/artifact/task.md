# Task Artifact

## Purpose

A task artifact defines what the worker should do.

The task must be specific enough to execute and review.

## Required Fields

A task should include:

- title
- objective
- scope
- allowed files
- forbidden files
- required commands
- expected output
- risk level

## Scope

The task must define what is included.

The task should also define what is excluded.

## Good Task

A good task is:

- small
- testable
- reviewable
- tied to current context
- bounded by explicit files or directories

## Bad Task

A bad task is:

- vague
- too broad
- mixed with unrelated goals
- dependent on hidden assumptions
- impossible to test

## Handoff

The task is given to the worker.

The worker must not silently expand the task.
