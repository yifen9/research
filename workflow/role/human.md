# Human

## Purpose

The human is the final authority.

The human decides whether an accepted change should be committed, revised, delayed, or discarded.

## Responsibility

The human controls:

- research direction
- architecture judgment
- final approval
- repository history
- publication strategy
- risk tolerance

The human may override the reviewer.

## Human Approval

Before approval, the human should inspect:

- worker proposal
- reviewer result
- repository diff
- latest run summary
- check result

## Decision

The human may decide:

- approve
- reject
- request revision
- postpone
- retire worker
- change task scope

## Commit Rule

A committed agent change should be atomic.

Each accepted change should correspond to one clear commit.

The commit should be easy to revert.
